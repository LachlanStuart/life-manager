Life Manager

Choose where your workspace lives.

Choose an existing data directory or a new folder. Your database, attachments and integration settings stay together.

Use 0 to choose an available port. A fixed port keeps browser bookmarks stable.

Use only on a trusted private network. There is no sign-in. This Mac must stay awake for other devices to connect.

Connect to an existing Life Manager server. Quitting this app leaves that server running. Local media and widget actions belong to the server’s computer.
