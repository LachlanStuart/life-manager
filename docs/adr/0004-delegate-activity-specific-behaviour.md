# Delegate activity-specific behaviour to widgets and external applications

The platform provides embedded widget rendering, a callable interface shared by widgets and local agents for ordinary application operations, and a way to open external applications. Feed-specific interactions belong to widgets; video playback, file serving, and the agent that arranges windows belong to external applications. This supports varied personal activities through a common item-and-page model without making their specialised capabilities part of the platform; individual widget designs are deferred.
